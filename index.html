ItemiSet draws itemized area-proportional Euler diagrams. Each gene, protein or other item gets one cell, so a region's area is its count and its contents can be read straight off the figure.

Tap or hover a cell to see where it belongs. Example: proteins found by BioID with three P-body baits in human cells. Name colours mark three gene families, chosen for illustration.

Data: Youn et al. (2018) Mol Cell 69:517, high-confidence hits via BioGRID 5.0.262 (MIT License).

Switch to counts and the question comes back.

A Venn diagram tells you that 24 proteins came down with all three baits. It doesn't tell you which 24, so the next step is always a lookup table. ItemiSet puts the table inside the diagram. The roster is the picture, and the picture is still drawn to scale.

Position is membership

A cell's place in the diagram says which sets it belongs to, exactly as in an Euler diagram.

Area is the count

One cell per item, so every region's area is exactly proportional to its size. Nothing is fitted or approximated.

Text is the identity

Following Tukey's advice to make each mark meaningful, the mark is the item's own name.

Type carries more

Text colour, weight and style can encode annotations such as GO terms or enrichment scores.

How a layout is built

For up to three sets, ItemiSet doesn't search for a layout. It fills a fixed template, then picks the bottom set and three column widths that give the best shape. That's a few thousand candidates, checked in milliseconds.

Zones are connected

Each zone is a contiguous stretch of a back-and-forth path, and such stretches are always one piece.

Sets have no holes

Every set is column-convex: in each column its cells form one unbroken run, which rules out holes.

Sets are connected

Neighbouring columns share the baseline row. The bottom set is joined by its band, with reported filler cells in rare cases.

Try it with your own lists

Paste one item per line, or separate them with spaces or commas. Add a number after a colon (for example CNOT1:42) and the text weight will show it. Everything runs in your browser.

Use it from Python

The Python package draws publication figures as PNG, PDF or SVG, with names kept as editable text. It reads CSV, TSV and Excel files, either as a membership table or as one column per set.

# install
pip install git+https://github.com/adamcc/itemiset

# from the command line
itemiset hits.csv -o hits.pdf --zones-out zones.csv
# in Python
from itemiset import plot, load_example

ex = load_example("pbody")
plot(ex["sets"], out="pbody.pdf",
     categories=ex["categories"])

Why it stops at three sets

Light cyan, magenta and yellow, multiplied like inks, give exactly seven distinguishable tints. Three sets have exactly seven zones. Tap a tint to see which sets make it.

The geometry also runs out

With one cell per item, sparse data can make an exact layout impossible. Picture five baits that share a single prey and nothing else. That prey is one cell with four sides, but all five private regions must touch it directly, because there are no in-between overlaps to route through. Polyomino Venn diagrams exist for any number of sets, but only when every combination is present and all regions are the same size. Real bait data have neither property.

What to use instead

  1. 2–3 sets: ItemiSetEvery zone connected and exactly proportional, from a simple template.
  2. 4 sets: itemized Karnaugh mapExplored as a prototype. Set labels become brackets along the margins instead of traced outlines.
  3. 5 or more sets: itemized UpSet plotProposed in the white paper. Each bar becomes a stack of member names, so stack height still shows the count.

ItemiSet

Say “item-EYE-set” to itemize your sets.

The name ties the tool to the Itemized Set Diagrams of the white paper, and the singular follows UpSet's lead: it names the tool, not the number of sets. The diagrams it makes are itemized area-proportional Euler diagrams. In set-theory terms, each set is drawn in roster form, with every element listed, rather than by its size alone.

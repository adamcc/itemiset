From working script to citable tool.

The prototype script is now an nbdev package with notebook tests, and a JavaScript port of its layout runs this website. This plan takes it to a tested, documented, citable release. Tasks marked done are done in the repository; your own ticks are saved in this browser only.

Five phases

    What the tests prove

    The correctness argument gives the test suite its targets. These checks run on the layout itself, not on rendered images, so they're exact and fast enough to run on thousands of random inputs. Both the Python package and the JavaScript port run them.

    InvariantHow it is checked
    One cell per itemEvery input item appears exactly once; filler and ∅ placeholder cells are flagged and never counted.
    Each set is one pieceA flood fill from any cell of the set reaches all of its cells.
    No set has a holeA flood fill from outside the bounding box reaches every cell that isn't in the set.
    Each zone is one pieceThe same flood-fill test, run on every non-empty zone.
    No stray white pocketsAll empty space connects to the outside edge, so blank cells can't be misread as members of a set.

    Keeping two implementations in step. Python is the reference. A notebook lays out over 200 inputs and saves every cell; the JavaScript tests must reproduce them exactly, so a change to either side that moves a single name fails the build.

    Risks to watch

    Long names widen every cell

    Cell width follows the longest name, so one long identifier stretches the whole grid. Options: truncation with a key, or per-column widths.

    A readability ceiling

    Past a few hundred items the text gets small. The docs should say where that limit is, measured on real figures.

    Filler cells

    Rare data need a strip of blank cells to keep the bottom set in one piece. The layout already picks another bottom set to avoid this, and reports it when it can't.

    Colour vision

    The CMY tints must not be the only cue. Outlines and set labels need to carry membership on their own, including in greyscale print.

    The novelty claim

    The template was put together from standard parts. Check it against mosaic cartograms, waffle charts and Chow and Ruskey's work before calling it new.

    Labels on tiny diagrams

    In the Python figures, a set label can be longer than its set is tall, and then it runs into the title. Very small diagrams need a different label placement.

    Decisions still open

    • LicenceApache-2.0 is planned. Until a licence is added, the code is all rights reserved, so others can read it but not reuse it.
    • Default bottom setCurrently chosen automatically by layout score, which avoids filler. The alternative is the last set in input order, which is more predictable.
    • Order within zonesNames sort naturally (CNOT2 before CNOT10). Ordering by score could become an option, in both implementations at once.
    • Four sets in 1.0?Suggested no. Ship 2–3 sets well, and keep the Karnaugh-map layout as an experimental module.

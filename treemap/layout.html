Layout

Itemized treemaps: a hierarchy of groups in, named grid cells out.

An itemized treemap shows how a set splits into subsets, and subsets into sub-subsets, with every member written out. Each item is one cell of a grid; each group, at every depth, is one connected region of cells; and the whole map is a rectangle whose only carve-out is the end of its last column.

How the cells are placed

Cells are laid along a snake: down the first column, up the second, down the third, and so on, through a grid h rows tall. Every group gets one unbroken run of that path, so every group’s region is connected, at every depth, whatever the sizes.

Each group spends one to three cells on its header (its name). The header goes where it reads best, tried in a fixed order:

  1. a whole row at the top or bottom edge of the region, so the header has no names beside it (wide: one line across cells; tall: the label broken down one column, one line per cell);
  2. otherwise the region’s top-left cell (or, when the region starts with a stub at the foot of a column, the top of the column holding most of it);
  3. otherwise the first cells of the region’s run.

Moving a header can leave a subgroup’s run touching its neighbour only at a corner, so every choice is checked and the search backs up when needed. The last option always works, because the remaining runs are then still pieces of the snake.

Names inside a group are filled column by column, top to bottom, in natural order, so the reading order does not depend on which way the snake runs.

The layout depends only on integers: item counts and each header’s size in cells (Group.header_span). Measuring text to choose those sizes happens in treemap.render.prepare.

Item

def Item(
    name:str, value:float | None=None, numeral:str | None=None
)->None:

One member of the map: its name, and optionally a value and the numeral to print before the name.

build_tree turns (path, item) records into a tree, where path names the item’s group at each level, e.g. ("Asia", "Eastern Asia"). Subgroups smaller than min_group are pooled into one “other” subgroup, and a group left with a single subgroup absorbs it. Siblings are ordered largest first (ties in natural order); groups named in last go at the end, in that order.

recs = [(("Fruit", "Citrus"), Item(n)) for n in ["lime", "lemon", "orange"]] + \
       [(("Fruit", "Berry"), Item(n)) for n in ["fig"]] + \
       [(("Vegetable", "Root"), Item(n)) for n in ["carrot", "beet"]]
t = build_tree(recs, min_group=2)
test_eq([c.name for c in t.children], ["Fruit", "Vegetable"])
test_eq([c.label or c.name for c in t.children[0].children], ["Citrus", "other"])   # Berry (1 item) pooled
test_eq([it.name for it in t.children[1].items], ["beet", "carrot"])               # lone subgroup merged
test_eq(t.n_items(), 6)
test_eq(t.n_cells(root=True), 6 + 2 + 2)   # items + top-level headers + Fruit's two subgroup headers
test_fail(lambda: build_tree([(("A",), Item("x")), (("A", "B"), Item("y"))]), contains="both items and subgroups")

def Placed(
    kind:str, path:tuple, item:__main__.Item | None=None, group:__main__.Group | None=None, span:tuple=()
)->None:

What sits in a cell: an item, or part of a group’s header.

The grid’s height is chosen to bring the map’s shape close to target_aspect (width over height), given each cell’s shape (cell_aspect), while avoiding a nearly empty last column. Every height from 1 up is scored, the score is rounded to an integer, and the first lowest wins.

def text_grid(lay):
    rows = [["." for _ in range(lay.cols)] for _ in range(lay.h)]
    for (c, r), p in lay.cells.items():
        rows[r][c] = "#" if p.kind == "header" else p.item.name[0]
    return "\n".join("".join(r) for r in rows)

Randomised check

Random trees one to three levels deep, with random header sizes, laid out at every height: every layout must keep all its guarantees.

def random_tree(rng, depth, prefix="g"):
    g = Group(prefix)
    g.header_span = rng.choice((1, 1, 2, 3))
    g.header_lines = ["x"] * g.header_span if rng.random() < 0.6 else None
    if depth == 0:
        g.items = [Item(f"{prefix}i{k}") for k in range(rng.randint(1, 12))]
    else:
        g.children = [random_tree(rng, depth - 1, f"{prefix}.{k}") for k in range(rng.randint(1, 6))]
    return g

n_layouts = 0
for seed in range(60):
    rng = random.Random(seed)
    root = Group("root", children=[random_tree(rng, rng.randint(0, 2), f"t{k}") for k in range(rng.randint(1, 8))])
    for h in range(2, min(root.n_cells(root=True), 40) + 1):
        res = check_layout(layout_tree(root, cell_aspect=3, h=h))
        assert all(res.values()), (seed, h, res)
        n_layouts += 1
print(n_layouts, "random layouts, all valid")
